#### Стык питонизатора:
- **SQLAlchemy(+ драйвер для pgsql - asyncpg)** - ОРМ
- **Alembic** - Управление миграциями
- **Repository и Unit of Work** - паттерны проектирования
- **Pytest (стандарт для Python) и HTTPX для асинхронных запросов к API** - Тестирование

Как они связаны:
```text
  Клиент
        │
        ▼ HTTP
   ┌─────────┐
   │ FastAPI │  ← валидирует запрос через Pydantic
   └────┬────┘
        │ вызывает функцию
        ▼
   ┌─────────────┐
   │ SQLAlchemy  │  ← работает с объектами Python
   └──────┬──────┘
          │ генерирует SQL
          ▼
     ┌─────────┐
     │   БД    │  ← PostgreSQL / SQLite / MySQL
     └─────────┘
          ▲
          │ схема управляется
     ┌─────────┐
     │ Alembic │
     └─────────┘
```


```text
Клиент
  │  JSON
  ▼
┌──────────────────────────────────────┐
│ FastAPI                              │
│  ┌────────────────────────────────┐  │
│  │ Pydantic                       │  │ ← валидация входа/выхода
│  │  • UserCreate (что прислали)   │  │
│  │  • UserRead   (что отдаём)     │  │
│  └────────────────────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │ SQLAlchemy                     │  │ ← работа с БД
│  │  • User (таблица)              │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
  │  SQL
  ▼
┌──────────┐
│   БД     │
└──────────┘
```

Как данные текут через Pydantic:
```text
Клиент → JSON
   │
   ▼
[Pydantic UserCreate]  ← валидация + парсинг
   │
   ▼
FastAPI-функция
   │
   ├── создаёт [SQLAlchemy User]
   │        │
   │        ▼
   │      БД
   │
   ▼
[SQLAlchemy User] ← читаем из БД
   │
   ▼
[Pydantic UserRead]  ← сериализация + фильтрация полей
   │
   ▼
JSON → Клиент
```
